# 本训练使用的 DexTrack 参考

训练轨迹 inspect_1 与留出轨迹 lift，各300帧；加载时依次拼成600帧。每条轨迹边界独立，不从inspect最后一帧跨到lift第一帧。

`*_bounded.npz` 中 qpos 是当前训练使用的限位/接触重定向结果，hand_qvel 是相应手关节速度。`*_source.npz` 保留进入该步骤之前的处理参考，训练从中取物体速度，并核对物体位置未被重定向步骤修改。具体读取见 src/hand_training/data.py。

模型 qpos 每帧23个数：前16项为手关节角，后7项为物体位置xyz和四元数wxyz。qvel每帧22个数：前16项为手关节角速度，后6项为自由物体速度，具体坐标约定服从MuJoCo和HandLayout转换。四元数不是四个自由度。

固定手掌、重力-X是当前验证任务的设置；并非完整复现原运动基座、原PhysX仿真或硬件。参考间隔配置为0.0166s，并非对原始采集时间戳的核验结果。

source_manifest.json保留此前数据处理来源记录；其中历史路径仅作来源说明，运行不读取这些路径。本目录是两条轨迹的训练子集，不是DexTrack原始全量数据集。
